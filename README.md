# 교육용 도구 — 기본경로판 (`~/edu_base/`)

> **데이터는 lerobot 기본 경로(`~/.cache/huggingface/lerobot`)에 쌓인다.**
> 새로 설치한 PC 라면 `config.sh` 를 아예 안 고쳐도 된다.
> 이 PC 에서 그 경로는 심링크가 아니라 **진짜 폴더**이고, 밑에 `calibration/` 과
> `data/` 가 들어 있다. 프로젝트 경로판(`edu/`)은 이 PC 에 없다 — 이 폴더 하나만 쓴다.

8시간 교육에서 **참가자가 순서대로 실행하는** 스크립트 묶음.
번호가 곧 진행 순서다. 번호 붙은 것만 실행하고, 나머지는 건드리지 않는다.

## 고치는 자리는 `config.sh` 하나뿐

포트·카메라·데이터셋 이름·학습 스텝·체크포인트 경로가 전부 여기 모여 있다.
**스크립트 본문은 열지 않는다.** 환경변수로 한 번만 덮어쓸 수도 있다.

```
STEPS=10000 edu3-1                   # 이번 한 번만 1만 스텝
EDU_NAME=so101_teamB edu2-3          # 팀별로 데이터셋을 나눌 때
RUN=2 edu3-1                         # 2차 학습 — 1차 결과를 남긴 채
```

## 1차와 2차를 나누는 법 — `RUN`

데이터를 보강한 뒤 다시 학습할 때 **`RUN` 만 올린다.** 출력 폴더가 회차별로
나뉘어 1차 결과가 남고, 롤아웃도 같은 회차를 가리킨다.

```
edu2-3 --resume=true    # 보강 30편 이어찍기
RUN=2 edu3-1            # 2차 학습 (1차는 그대로)
RUN=2 edu4-1            # 2차 모델 굴리기
RUN=1 edu4-1            # 1차와 비교
```

⚠ **학습에 `--resume` 을 쓰지 않는다.** 데이터가 늘어난 뒤 이어학습을 걸면
에러 없이 한 스텝도 안 돌고 끝나거나 1차 결과를 덮어쓴다. 처음부터 새로 돌린다.

> **처음 쓰신다면 [사용법.md](사용법.md) 부터.** 한 장짜리다.

## 단축 명령

어느 폴더에서든 **`edu1-1`** 처럼 치면 바로 돈다. `~/.local/bin` 심링크다.

```
edu-set                 새 PC 맞추기 · 준비 점검
edu0-1  edu0-2      보정 (팔로워 · 리더)
edu1-1  edu1-2      텔레옵
edu2-1  edu2-2  edu2-3  edu2-4   녹화·병합
edu3-1  edu3-2      학습
edu4-1  edu4-2      롤아웃
```

환경변수도 그대로 붙는다 — `STEPS=500 edu3-1`, `RUN=2 edu4-1`.
폴더를 다른 자리로 옮기면 심링크를 다시 걸어야 한다.

## 폴더째 옮겨도 돈다

**바깥을 참조하지 않는다.** 이 폴더만 복사하면 다른 PC 에서도 그대로 쓸 수 있다.
고칠 곳은 `config.sh` 맨 위 **두 줄**뿐이다.

```
LEROBOT_HOME   데이터·모델이 쌓이는 곳  (이 PC : ~/.cache/huggingface/lerobot)
CONDA_SH       conda 초기화 스크립트 경로 (이 PC : ~/miniforge3/etc/profile.d/conda.sh)
CONDA_ENV      conda 환경 이름           (이 PC : lerobot)
```

영상 확인과 손실 곡선도 프로젝트의 원본을 부르지 않고 **폴더 안의 `_view.sh` ·
`_watch.sh`** 를 쓴다. 원본이 갱신돼도 교육용은 영향받지 않고, 반대도 마찬가지다.

## 2-2 의 모터 그래프

편마다 **관절 6개의 움직임**을 접었다 펼 수 있다. 「모터 그래프」를 누르면 나온다.

- **실선** = 팔로워가 실제로 간 각도 (`observation.state`)
- **점선** = 리더가 시킨 각도 (`action`)
- **Δ** = 둘의 평균 차이(도)

두 선이 벌어질수록 팔이 명령을 못 따라간 것이다. 어깨·팔꿈치처럼 무거운 관절에서
Δ 가 크게 나온다 — 데이터가 왜 완벽하지 않은지를 눈으로 보여줄 수 있다.
그리퍼는 여닫이라 계단 모양이 나온다.

**12편까지는 그래프가 펼쳐진 채로 열린다.** 그보다 많으면 자동으로 접히고 영상도
미리 읽지 않는다 — 117편을 다 펼치면 5MB 에 그래프 1,400개라 브라우저가 멈춘다.
접힌 것은 제목을 누르면 그 편만 펼쳐진다. 기준을 바꾸려면 `VIEW_OPEN_MAX` 를 준다.

묶음 단위(`edu2-3` 의 `[v]`)로 보면 늘 10편이라 항상 펼쳐진 상태로 열린다.

## 이상한 판 자동 표시

2-2 는 **찍힌 판을 검사해 이상한 것만 붉게 표시한다. 지우지 않는다.**
번호만 알려주고, 다시 찍을지 그냥 둘지는 사람이 판단한다.

| 표시 | 뜻 |
|---|---|
| **시간상한에 걸림** | 최대 길이를 두 판 이상이 정확히 공유 = 그게 상한. 끝까지 못 끝낸 판 |
| **너무 짧다** | 중앙값의 55% 미만 — 손이 미끄러졌거나 일찍 끊긴 판 |
| **너무 길다** | 중앙값의 145% 초과 — 헤맨 판 |
| **어긋난 판** | 데이터 행 수와 영상 프레임 수가 안 맞는다 — 녹화 중 끊김·인코딩 오류.<br>카메라마다 값이 다르면 **두 스트림이 서로 틀어진 것**이라 더 나쁘다 |
| **영상 중복** | 다른 판과 영상 구간이 겹친다 — 같은 장면이 두 판에 들어갔다 |

「시간상한」과 「어긋난 판」은 연구용 도구가 `--capped` · `--broken` 으로
**골라서 지우던** 기준과 같다. 교육용은 **지우지 않고 표시만** 한다.
(연구용 스크립트는 이 PC 에 없다 — 폴더 안의 `_drop.sh` 가 같은 일을 한다.)

기준은 **그 데이터셋 자신의 중앙값**이다. 과제마다 길이가 달라 고정값을 못 쓴다.
바꾸려면 `VIEW_SHORT_RATIO` · `VIEW_LONG_RATIO` 를 앞에 붙인다.

아래 막대에서 **「이상한 판만」** 을 누르면 표시된 것만 남고, **「번호 복사」** 로
번호를 받아 다시 찍을 판을 고른다.

## 같이 들어 있는 모델 (`models/`)

폴더 안에 넣어 두었다. **따로 챙길 게 없다.**

| | 크기 | 쓰는 곳 |
|---|---|---|
| `act_golden/` | 198 MB | **4-2 안정본** — `act_edu3_100` 060000 (ACT · sync) |
| `act_golden.bak-cylinder_v1/` | 198 MB | 옛 안정본 (`so101_cylinder_v1` · 50k). 안 쓰면 지워도 된다 |
| `torch-cache/` | 45 MB | ACT 가 쓰는 ResNet18 백본 |

`config.sh` 가 `TORCH_HOME` 을 이 폴더로 돌려놔서, **인터넷 없이도 돈다.**
`models/` 는 약 **243 MB**, 폴더 전체도 그만큼이다.

> SmolVLA 를 안정본으로 쓰려면 VLM 백본 캐시가 따로 필요하다. `models/hf-cache/`
> 를 만들어 넣으면 `config.sh` 가 그것을 `HF_HOME` 으로 잡는다. 이 PC 에는 없다.

다른 모델을 안정본으로 쓰려면 `config.sh` 의 `STABLE_CKPT` 한 줄만 바꾼다.
SmolVLA 계열이면 `STABLE_INFERENCE_TYPE=rtc` 로 두고 `STABLE_RENAME_MAP` 을 채운다.

## 새 PC 로 옮기기 (lerobot 이 깔려 있다는 전제)

**두 가지만 복사하면 된다.**

| 무엇 | 크기 | 어디로 |
|---|---|---|
| 이 폴더 (스크립트만) | 276 KB | 아무 데나 |
| `~/.cache/huggingface/lerobot/calibration/` | 36 KB | 새 PC 의 같은 자리 |
| (모델은 폴더 안 `models/` 에 이미 들어 있다) | 243 MB | 따로 챙길 것 없음 |

보정값은 폴더 안에 없다 — 데이터 루트 아래 있다. **같은 팔을 가져간다면 복사**하고,
다른 팔이면 새 PC 에서 `edu0-1` · `edu0-2` 로 새로 잡는다.
⚠ 같은 팔을 새로 보정하면 안정본(`models/act_golden`)을 학습한 데이터와 관절 값이 어긋날 수 있다.

그다음 폴더 안에서 **`bash edu-set.sh`** — 새 PC 에서 칠 **첫 명령**이다.
단축 명령(`edu-set` · `edu0-1` ~ `edu4-2`)을 걸고, 포트·카메라를 잡고, 준비 상태까지 점검한다.

⚠ **단축 명령은 폴더에 안 따라온다.** 옮긴 직후에는 `edu-set` 조차 없으므로
**처음 한 번은 반드시 `bash edu-set.sh`** 로 부른다. 그 뒤로는 어디서든 `edu-set`.

포트가 어느 팔인지는 **사람이 정한다.** 도구는 케이블을 뽑았다 꽂게 해서 사라진 포트를
알려줄 뿐이고, 넣기 전에 미리보기와 확인을 받는다. `config.sh.bak` 으로 백업도 남긴다.



선택 — `edu4-2` 안정본을 쓰려면 체크포인트 폴더(약 200 MB)도 옮기고
`config.sh` 의 `STABLE_CKPT` 를 그 경로로 맞춘다. 데이터셋은 새로 찍으면 되니 안 옮겨도 된다.

## 다른 PC 로 옮길 때

**폴더째 복사하면 도구·모델·백본은 그대로 간다.**
⚠ 다만 **파이썬 환경(lerobot·torch·pandas·rerun)은 폴더에 없다** — 그 PC 에 미리 깔려 있어야 한다.
GPU 드라이버와 직렬포트 권한도 폴더가 못 옮긴다.

확인한 것 :

| 상황 | 결과 |
|---|---|
| 프로젝트 밖으로 옮김 | 스스로 자기 위치를 찾는다 |
| 기본 경로가 심링크가 아닌 진짜 폴더 | 정상 |
| conda 가 다른 위치에 있음 | 흔한 설치 위치를 차례로 찾는다 |
| conda 가 아예 없고 venv·시스템 파이썬만 | 그 파이썬을 쓴다 (안내 한 줄) |
| 파이썬도 준비 안 됨 | 무엇을 하면 되는지 알려주고 멈춘다 |
| `google-chrome` 이 없음 | chromium · firefox · xdg-open 순으로 찾고, 다 없으면 파일 경로를 알려준다 |
| `lerobot` 명령이 없음 | 보기·판정은 되고, 녹화·학습은 안 된다고 알린다 |

바꿀 수 있는 값 — `CONDA_SH` · `CONDA_ENV` (config.sh) · `EDU_BROWSER` (환경변수).

## 안전장치

전부 자동으로 걸린다. 참가자가 신경 쓸 것은 없다.

- **미리보기 → `[Y/n]` → 실행** — 모든 명령이 실행 전에 화면에 그대로 보인다
- **포트 확인** — 없거나 다른 프로그램이 쓰는 중이면 멈추고 붙어 있는 포트를 나열한다
- **GPU 확인** — 학습·롤아웃 전에 `nvidia-smi`. 이미 도는 작업이 있으면 물어본다.
  `nvidia-smi` 가 실패하면 "안 돌고 있다"가 아니라 **"확인 못 함"**으로 보고 멈춘다
- **지우기 확인** — 데이터셋·학습출력을 지울 때 크기·편수를 보여주고 묻는다.
  안전 범위(`lerobot/data/` · `lerobot/outputs/train/` 의 **하위 폴더**) 밖은 손대지 않고,
  상위 디렉터리 자체는 절대 지우지 않는다.
  **학습 출력은 기본이 「지우지 않음」**(`[y/N]`) 이라 Enter 로 1차 결과가 날아가지 않는다
- conda 활성화와 `LD_LIBRARY_PATH` 는 자동. 참가자가 붙일 필요 없다

`-y` 는 **실행 확인만** 건너뛴다(강사용). **삭제와 GPU 경고는 그대로 묻는다** —
되돌릴 수 없는 자리에서 자동 승인은 하지 않는다.

녹화 중 `Ctrl+C` 를 눌러도 바로 끝나지 않는다. lerobot 이 영상을 마저 저장할
때까지 기다린다 — **창을 닫지 않는다.**

## 실기 검증 상태

⚠ **아직 로봇으로 한 번도 안 돌렸다.** 문법 검사와 정적 검토만 마쳤다.
리허설 때 1-1 부터 순서대로 확인한다. 특히 1-1(카메라 없는 텔레옵)은
기존에 없던 형태라 소스상 기본값만 확인한 상태다.

## 파일을 더 추가할 때

- 번호 체계를 지킨다 — `<단계>-<순번>_<이름>.sh`. 파일명 본문은 하이픈, `_` 는 번호와 이름 사이만
- 새 설정값은 **반드시 `config.sh` 에** 넣는다. 스크립트 본문에 경로를 박지 않는다
- 하드웨어·GPU·삭제가 들어가면 `common.sh` 의 `need_ports` / `gpu_guard` / `ask_delete` / `run_cmd` 를 쓴다
- lerobot 플래그는 기억으로 쓰지 않는다. 설치된 lerobot 소스(`~/miniforge3/envs/lerobot`)에서 확인해 옮긴다

## 이 폴더가 따로 있는 이유

연구용 스크립트(`cyl-*` `drum3-*` `slot-*`)는 값이 수시로 바뀐다.
교육 당일에 그걸 고치면 연구 쪽이 깨지고, 반대도 마찬가지다.
**교육용은 설정을 한 파일로 모으고 바깥 의존을 끊어 격리**했다.
그래서 이 PC 처럼 연구용 폴더가 없는 곳에서도 `~/edu_base/` 하나로 끝난다.

`_view.sh` · `_watch.sh` 는 검증된 `drum3-view.sh` · `train-watch.sh` 의 사본이다
(2026-08-19 시점). 새로 만들지 않고 가져와 경로만 폴더 안으로 돌렸다.
원본에 개선이 생기면 다시 복사해 오되, `config.sh` 를 읽는 머리 부분과
conda 경로 두 곳을 같은 방식으로 손봐야 한다.
