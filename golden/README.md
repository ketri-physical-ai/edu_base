# 골든 데이터셋 자리

여기에 **미리 잘 찍어 둔 기준 데이터셋**을 넣는다. 비어 있으면 `edu2-4` 가 안내만 하고 멈춘다.

```
golden/
└── so101_golden/          ← 이 이름 (config.sh 의 GOLDEN_NAME)
    ├── meta/
    ├── data/
    └── videos/
```

lerobot 데이터셋 폴더를 **통째로** 넣으면 된다.

## 합치기 전에 맞아야 하는 것

| 항목 | 왜 |
|---|---|
| **fps** | 다르면 병합이 거부된다 |
| **카메라 이름·개수** | `top` · `wrist` 두 개로 같아야 한다 |
| **과제 문장** | 다르면 데이터셋이 두 과제로 갈라진다 |

`edu2-4` 가 합치기 전에 이 셋을 대조해서, 다르면 멈추고 무엇이 다른지 알려준다.
