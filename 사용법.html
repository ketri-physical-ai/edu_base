값 바꾸기

config.sh 한 파일만 수정하면 됩니다. 한 번만 바꿀 때는 명령 앞에 붙이세요.

STEPS=10000 edu3-1 이번만 1만 스텝 RUN=2 edu3-1 2차 학습 (1차 결과 유지) RUN=2 edu4-1 2차 모델 롤아웃 NUM_EPISODES=50 edu2-3 이번만 에피소드 50개 DISPLAY_DATA=false edu1-2 화면 없이 (rerun 이 없을 때)

자주 쓰는 값 — NUM_EPISODES(총 에피소드 수) · SESSION_SIZE(세션당 에피소드 수) · EPISODE_TIME_S/RESET_TIME_S(녹화·대기) · STEPS/BATCH_SIZE(학습) · CAM_TOP/CAM_WRIST(카메라 번호) · GOLDEN_NAME(골든 이름).

사

다른 PC 로 옮기기

이 폴더를 통째로 복사하면 됩니다 (243 MB). 모델과 백본이 폴더 안에 있어 인터넷 없이 실행됩니다.

폴더로 옮길 수 없는 것 — 파이썬 환경 · GPU 드라이버 · 직렬포트 권한. 인터넷이 될 때 아래 명령을 먼저 실행해 두세요.

pip install "lerobot[dataset,viz,feetech,smolvla]"

옮긴 뒤 bash ~/edu_base/edu-set.sh 한 줄이면 됩니다. 카메라 번호만 해당 PC 에서 다시 선택하세요.

보정값은 폴더 밖에 있음

<데이터루트>/calibration/robots/so_follower/<팔로워ID>.json <데이터루트>/calibration/teleoperators/so_leader/<리더ID>.json
  • 기본 ID 그대로라면 ~/.cache/huggingface/lerobot/calibration/…
  • 팔로워와 리더는 서로 다른 폴더에 있고, 파일 이름이 config.sh 의 ID 와 같아야 읽힙니다
  • 없어도 됩니다 — edu1-1 실행 시 새로 보정합니다

데이터는 함께 옮겨지지 않음

녹화본과 학습 결과는 데이터 루트에 저장됩니다. 폴더를 옮겨도 함께 옮겨지지 않으므로, 새 PC 에서는 참가자가 처음부터 녹화하게 됩니다. 골든 데이터만 폴더 안에 있어 함께 옮겨집니다.

아

골든 병합

미리 녹화해 둔 기준 데이터를 이번 녹화본에 병합해 학습 데이터를 늘립니다.

edu_base/golden/so101_golden/ ← lerobot 데이터셋 폴더를 통째로 복사

비어 있으면 edu2-4 가 안내만 하고 중단합니다. 이름은 config.sh 의 GOLDEN_NAME 으로 바꿀 수 있습니다.

병합 결과

병합 전 (에피소드 수) 병합 후 골든 2개 골든 2개 (그대로) so101_edu 50개 so101_edu_old 50개 ← 원래 녹화본 백업 so101_edu 52개 ← 병합본이 이 이름을 사용

데이터셋 이름이 같으므로 다음 단계가 간단합니다.

edu2-2 확인 RUN=2 edu3-1 학습 (1차 결과 act_edu_r1 유지) RUN=2 edu4-1 롤아웃 — ⚠ RUN=2 를 빼면 1차 모델이 실행됩니다

이름을 교체하기 전에 한 번 더 확인합니다. n 을 입력하면 병합본을 _merged 위치에 두고 그 병합본으로 학습하는 명령을 알려 줍니다. 되돌리는 명령도 마지막에 출력합니다.

병합 전 일치해야 하는 항목

edu2-4 가 먼저 대조하고, 하나라도 다르면 중단한 뒤 다른 항목을 알려 줍니다.

항목이유
fps · 해상도다르면 병합할 수 없습니다
카메라 이름 · 개수같은 키에 다른 영상이 들어갑니다
로봇 종류 · 관절 수데이터 구조가 어긋납니다
과제 문장데이터셋이 두 과제로 갈라집니다
카메라 시점 이름이 같아도 물리적으로 뒤바뀐 경우를 잡아냅니다

마지막 항목은 화면의 윤곽 복잡도로 판단합니다 — 상단은 책상·물체가 다 보여 복잡하고(약 1800), 손목은 흰 종이 클로즈업이라 단순합니다(약 140). 10배 넘게 차이 나므로 확실히 구분됩니다. 뒤바뀐 채로 병합하면 오류 없이 학습이 망가지므로 중단합니다.

안전장치

  • 원본이 삭제될 수 있는 경로를 차단합니다 — 병합본 경로가 골든이나 녹화본과 같거나 그 안팎이면(심링크로 우회해도) 시작 전에 중단합니다
  • _old 가 이미 있으면 덮어쓰기 전에 확인합니다 (기본값은 「삭제 안 함」)
  • 병합본이 실제로 생성된 것을 확인한 뒤에만 이름을 교체합니다
  • 병합 index 를 자동 교정하고, 실패하면 그 사실을 알려 줍니다
